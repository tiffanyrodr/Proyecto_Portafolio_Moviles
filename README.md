# Portafolio Profesional Interactivo

Aplicación móvil desarrollada con React Native y Expo para el Proyecto Programado 1 del curso Programación para Dispositivos Móviles.

## Descripción

Esta aplicación funciona como un portafolio profesional interactivo donde se presenta información personal, habilidades y proyectos desarrollados.

Actualmente me encuentro estudiando Ingeniería Industrial en la Universidad de Costa Rica (UCR) y el Técnico en Desarrollo de Aplicaciones en el Tecnológico de Costa Rica (TEC).

Además, este proyecto forma parte de mi proceso de aprendizaje en desarrollo móvil utilizando React Native y Expo.

## Funcionalidades

- Pantalla de inicio con perfil profesional.
- Navegación mediante Bottom Tabs y Stack.
- Lista de proyectos utilizando FlatList.
- Pantalla de detalles para cada proyecto.
- Sección de habilidades.
- Diseño responsive con Flexbox.
- Uso de Hooks como useState.
